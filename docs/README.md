# Harness 文档索引

本目录是小说阅读网站的仓库内 Harness。它的作用是让后续 AI 辅助开发依赖稳定、可版本化的项目上下文，而不是依赖临时聊天记录。

## 文档列表

- `product-spec.md`：产品目标、MVP 范围、用户角色和验收标准。
- `ui-spec.md`：页面清单、交互状态和视觉约束。
- `architecture.md`：系统形态、技术栈、边界、存储和部署方式。
- `api-contract.md`：前后端集成的第一版 API 契约。
- `data-model.md`：MySQL 数据模型和本地文件存储规则。
- `security.md`：认证、权限、上传和敏感信息约束。
- `commands.md`：开发和检查所需的确定性命令。
- `harness/principles.md`：本项目采用的 Harness Engineering 原则。
- `harness/status.md`：当前 Harness 完整度和进入下一阶段的条件。
- `team/roles.md`：多角色 Agent 团队职责。
- `team/workflow.md`：从需求/Bug 到交付的团队流程。
- `team/handoff-template.md`：角色任务交接模板。
- `exec-plans/`：分阶段执行计划。
- `decisions/`：已经接受的架构和产品决策。
