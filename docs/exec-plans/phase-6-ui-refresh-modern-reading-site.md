# Phase 6：现代中文阅读站风格 UI 改版

## 状态

已完成。

## 任务类型

- UI 调整
- 前端实现
- 测试补强
- Harness 更新

## 背景

当前 MVP 功能已经完整，但前端界面整体偏通用脚手架风格，首页、搜索、详情、阅读和后台页面之间的视觉语言不够统一，无法体现“本地小说阅读网站”的产品气质。

用户已确认本轮改版范围为“前台 + 我的作品 + 管理后台整体统一”，并确认风格方向为“参考中文网文站的信息架构，但整体更现代、更干净”。

## 目标

1. 将首页、搜索页、详情页和阅读页升级为更接近中文阅读站的信息组织方式。
2. 保留中文网文站常见的顶部导航、分类入口、榜单侧栏、书籍卡片和沉浸式阅读器，但使用自有配色、装饰和布局比例。
3. 将登录、注册、账号、我的作品、上传、后台管理和分类管理统一到同一套设计系统中。
4. 保持现有 API、权限和业务逻辑不变，仅调整前端结构、样式和展示文案。
5. 补充桌面端和移动端的视觉一致性，避免重叠、溢出和断裂布局。

## 非目标

- 不复制起点中文网的品牌、Logo、视觉资产、精确布局或专有文案。
- 不修改后端 API、数据库结构、权限模型或业务规则。
- 不新增推荐算法、评论、书架、打赏、付费章节或其它 MVP 外功能。
- 不引入新的前端框架、状态管理方案或设计系统依赖。

## 默认实现假设

- 站点继续沿用当前品牌名和路由结构，只升级视觉表现。
- 前台页面强调阅读氛围和信息层次，后台页面保持工具型可操作性。
- 阅读器继续保留字号调节、浅色/深色主题和目录切换。
- 本轮以 CSS 重构和页面结构微调为主，不引入图片资产或远程字体依赖。

## 影响范围

- 产品：无功能范围变化，仅提升展示体验。
- UI：首页、搜索页、详情页、阅读页、登录注册、账号页、我的作品、上传页、后台页整体更新。
- 前端：`Layout`、书籍卡片、搜索表单、状态组件和多个页面组件会调整 DOM 结构和样式类名。
- 后端：无变化。
- API：无变化。
- 数据库：无变化。
- 测试：需要至少重新通过前端构建；如本地环境允许，补浏览器级验收。
- DevOps：无变化。
- 安全/权限：无变化。

## 契约变化

### API

无变化。

### 数据

无变化。

### UI 状态

- 首页：
  - 使用阅读站式头部、主视觉、分类入口、新书列表和榜单侧栏。
  - 保留加载、错误、空状态。
- 搜索页：
  - 使用更强的信息标题区、筛选区、结果摘要和分页区。
  - 无结果时展示明确空状态，不白屏。
- 小说详情页：
  - 强化书籍信息头部、阅读 CTA、登录提示和目录布局。
- 阅读页：
  - 保持沉浸阅读，增强纸张感、目录抽屉和操作栏层次。
- 登录/注册：
  - 统一为站点风格的入口页，而不是纯工具表单。
- 我的作品、上传、后台管理、分类管理、账号设置：
  - 统一为“编辑台”风格的工具页，和前台共享按钮、输入框、间距、颜色体系。

## 角色分工

- 主 Agent：更新 Harness、实施前端改版、运行验证、回填状态。
- UI Agent：定义整体视觉方向、页面组织方式和非复制边界。
- 前端 Agent：完成组件结构和 CSS 实现。
- 测试 Agent：执行构建验证并记录浏览器验收结果或缺口。

## 验收标准

- 首页、搜索页、详情页、阅读页形成统一的现代中文阅读站视觉风格。
- 登录/注册、账号、我的作品、上传和后台页面共享统一设计系统，不再割裂。
- 阅读页在桌面端具备舒适的行宽、留白、排版和目录切换体验。
- 移动端和桌面端均不出现明显重叠、溢出、不可点击区域。
- 现有业务功能路径不变，构建通过。
