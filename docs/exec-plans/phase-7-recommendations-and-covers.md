## 背景

当前首页已支持内联搜索与快速分类，并将搜索结果展示在首页主区域。但本轮需要进一步把“发现效率”和“内容呈现”做得更像阅读站，同时保持自有风格：

- 首页搜索结果与“最新入库”最多展示 8 本，避免信息噪声；超过 8 本时提供“查看更多”再跳转完整列表页。
- 将“章节热榜”调整为更稳定、可控的“推荐榜单”，排序依据为书籍的推荐度字段（确定性、可配置）。
- 书籍支持上传封面图，且在未上传封面时也必须稳定展示占位图（不返回 404 导致前端裂开）。

## 目标

1. 首页：
   - 搜索结果最多展示 8 本；超过 8 本才显示“查看更多”按钮，点击后跳转到搜索结果页。
   - “最新入库”最多展示 8 本；超过 8 本才显示“查看更多”按钮。
2. 推荐榜单：
   - 新增书籍字段 `recommendScore`（推荐度），按推荐度从大到小排序展示榜单。
   - 推荐度可由“管理员”和“书籍作者（owner）”编辑。
3. 封面：
   - 支持上传书籍封面，最大 10MB。
   - 支持常见图片格式（JPG/PNG/WebP）。
   - 未上传封面时，封面接口必须返回默认占位图，前端可直接使用 `coverUrl` 渲染。
4. 稳定性：
   - 书籍没有任何章节时，详情页仍可正常渲染并展示明确的空状态（不白屏）。

## 非目标

- 不做推荐算法或个性化推荐，仅做可配置的推荐度排序。
- 不引入第三方图床或对象存储，封面仍保存在本地文件系统（可挂载到 Docker volume）。
- 不复制竞品的封面素材或视觉资产。

## 默认实现假设

- `coverUrl` 使用后端接口路径（例如 `/api/books/{bookId}/cover`），保证永远可用：有封面返回封面文件，无封面返回占位图。
- 推荐榜单使用独立接口，默认分页，首页只取前 8 本。
- 推荐度字段默认 `0`，越大越靠前；同分时使用 `created_at desc` 或 `id desc` 做稳定排序。

## 影响范围

- 产品：发现页信息结构增强，新增推荐榜单与封面展示。
- UI：首页、书籍卡片、详情页封面区域、后台/作者管理页编辑项增加。
- 前端：API types 与 client、HomePage、BookCard、BookDetailPage、管理页表单增加封面与推荐度能力。
- 后端：books 表增量字段；新增推荐榜单查询；新增封面上传与封面读取（含占位图）。
- API：新增/调整书籍字段；新增推荐榜单接口；新增封面上传与读取接口。
- 数据库：books 表新增 `recommend_score`、`cover_path` 与索引。
- 测试：补充推荐排序、权限校验、封面占位图返回的回归测试；前端 build 验证。

## 契约变化

### API

- `BookSummary` / `BookDetail` 增加字段：
  - `recommendScore`：number
  - `coverUrl`：string
- 新增：
  - `GET /api/books/recommendations?page&pageSize`
  - `POST /api/books/{bookId}/cover`（multipart 上传）
  - `GET /api/books/{bookId}/cover`（返回图片；缺失时返回占位图）
- 修改：
  - `PATCH /api/books/{bookId}` 允许管理员或作者更新 `recommendScore`（同时保留 title/category/description）。

### 数据

- `books.recommend_score INT NOT NULL DEFAULT 0`
- `books.cover_path VARCHAR(255) NULL`

### UI 状态

- 首页：
  - 搜索/分类结果在首页主区域展示，最多 8 本，超过才显示“查看更多”。
  - 最新入库最多 8 本，超过才显示“查看更多”。
  - 侧栏榜单替换为“推荐榜单”。
- 详情页：
  - 无章节时显示空状态卡片或插画占位，而不是空白区域。
  - 封面永远有图（真实封面或占位图）。
- 管理页：
  - 增加封面上传入口（管理员 + 作者可用）。
  - 增加推荐度输入框（管理员 + 作者可用）。

## 验收标准

- 首页搜索结果和最新入库最多各展示 8 本，且“查看更多”只在超过 8 本时出现。
- 推荐榜单按 `recommendScore desc` 排序，接口与前端一致，且同分排序稳定。
- 管理员与作者都可以编辑推荐度与上传封面；非作者普通用户不可编辑他人书籍。
- 未上传封面时封面接口返回占位图（HTTP 200），前端稳定渲染。
- 书籍无章节时，详情页与阅读路径不会白屏或崩溃，页面提示清晰。
