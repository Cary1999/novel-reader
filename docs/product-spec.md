# 产品规格说明

## 产品目标

创建一个本地小说阅读网站，提供清晰的阅读型体验：发现小说、关键词搜索、查看书籍详情、按章节阅读，并允许用户上传和维护自己的小说，管理员维护全站内容和分类。

网站可以参考起点读书的产品结构和阅读模式，但不得复制其品牌、Logo、视觉资产、专有内容或精确界面。

## 用户角色

### 游客

- 可以访问公开首页。
- 可以搜索小说。
- 可以查看小说详情页。
- 不可以阅读章节正文，阅读章节需要登录。
- 可以注册和登录。

### 注册用户

- 可以登录和退出登录。
- 可以设置昵称和修改密码。
- 可以搜索小说。
- 可以阅读章节。
- 可以上传 `.txt` 小说。
- 可以新建小说并维护自己的章节。
- 只能编辑和删除自己创建或上传的小说。

### 管理员

- 拥有注册用户的全部能力。
- 可以访问后台上传页面。
- 可以访问后台小说管理页面。
- 可以访问分类管理页面。
- 可以访问系统设置页面并维护站点品牌信息。
- 可以上传 `.txt` 小说文件。
- 上传时可以触发自动章节解析。
- 可以修改小说基础信息。
- 可以新增、修改和删除章节。
- 可以删除整本小说。
- 可以新增、重命名和删除未被使用的分类。
- 可以设置站点图标、顶部品牌名称、副标题和首页主视觉文案。

## MVP 功能

### 认证

- 用户通过用户名和密码注册。
- 注册时昵称默认等于用户名。
- 用户通过用户名和密码登录。
- 登录用户可以修改昵称和密码。
- 后端签发认证会话或 Token。
- 后端能够识别管理员角色。

### 搜索

- 支持按书名、作者和可选关键词搜索小说。
- 返回基础书籍卡片信息：书名、作者、分类、简介摘要和最新章节信息。
- 首页展示分类入口、新书列表和简单榜单。榜单只按创建时间或章节数等确定性字段排序，不做推荐算法。

### 阅读

- 小说详情页展示元数据和章节列表。
- 章节阅读页展示章节标题和正文。
- 阅读器应提供舒适的排版和页面布局。
- 章节正文要求登录后访问。
- 阅读器支持基础字号、浅色/深色主题和章节目录切换。

### 后台上传

- 管理员可以上传 `.txt` 文件。
- 上传表单至少包含书名、作者、分类和简介。
- 后端校验文件类型和大小。
- 上传文件大小限制为 50MB。
- 后端将上传源文件保存到本地。
- 后端从 `第1章`、`第一章`、`Chapter 1` 等标题格式中解析章节。
- 解析后的章节元数据和正文应可用于阅读。
- 上传成功后展示解析结果摘要，包括章节数和首末章节标题。
- MVP 不做上传前章节预览。

### 用户作品管理

- 登录用户可以新建空小说。
- 登录用户可以上传 `.txt` 小说，作者由当前登录账号自动决定。
- 普通用户作品作者展示为系统内 `username`，不使用自由输入。
- 管理员上传或新建的小说作者展示为“系统”。
- 小说分类只能选择已有分类，不能在小说表单中输入新分类。
- 普通用户只能管理自己的小说和章节，管理员可以管理所有小说和章节。

### 后台小说管理

- 管理员可以搜索后台书籍列表。
- 管理员可以修改书名、作者、分类和简介。
- 管理员可以新增章节，新章节默认追加到目录末尾。
- 管理员可以修改指定章节标题和正文。
- 管理员可以删除指定章节，删除后章节序号保持连续。
- 管理员可以删除整本小说，删除后前台搜索、详情和阅读不可继续访问。
- 管理员可以新建空小说。
- 上传源文件和上传记录默认保留，用于追溯来源。

### 分类管理

- 分类列表公开可读，用于搜索和小说表单选择。
- 分类新增、重命名、删除仅管理员可操作。
- 已被书籍使用的分类不允许删除。

## MVP 暂不包含

- 付费章节。
- 评论和书评。
- 推荐算法。
- 超出简单列表的排行榜算法。
- 完整作者平台。
- 移动端 App。
- 第三方 OAuth。
- 分布式对象存储。

## 验收标准

- 新用户可以注册并登录。
- 已登录用户可以搜索并阅读种子小说或上传后的小说。
- 游客可以搜索和查看详情，但访问章节正文会被要求登录。
- 管理员可以上传 `.txt` 文件，并在上传后阅读解析出的章节。
- 管理员可以在后台修改小说基础信息和章节内容。
- 管理员可以新增、删除章节，并删除整本小说。
- 普通用户可以上传小说并管理自己的小说。
- 搜索无结果时必须展示空状态，不出现白屏。
- 后端可以通过 Docker 构建。
- 本地环境可以运行 MySQL 和本地上传文件存储。
