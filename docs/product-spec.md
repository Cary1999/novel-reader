# 产品规格说明

## 产品目标

创建一个本地小说阅读网站，提供清晰的阅读型体验：发现小说、关键词搜索、查看书籍详情、按章节阅读，并为获批作者提供独立创作端，为后台运营人员提供独立审核与治理后台。

网站可以参考起点读书的产品结构和阅读模式，但不得复制其品牌、Logo、视觉资产、专有内容或精确界面。

## 用户角色

### 游客

- 可以访问公开首页。
- 可以搜索小说。
- 可以查看小说详情页。
- 不可以阅读章节正文，阅读章节需要登录。
- 可以注册和登录。

### 读者

- 可以登录和退出登录。
- 可以设置昵称和修改密码。
- 可以上传头像。
- 可以搜索小说。
- 可以阅读章节。
- 可以把小说加入书架，并在我的书架中管理分组、置顶和批量操作。
- 可以申请成为作者。
- 不可以发布、上传或修改小说内容。

### 作者

- 拥有读者端的全部能力。
- 可以访问独立作者端。
- 可以上传 `.txt` 小说文件。
- 可以新建小说并维护自己的章节。
- 只能编辑和删除自己创建或上传的小说。
- 可以修改自己小说的基础信息、章节和封面。

### 审核人员

- 只能访问后台端。
- 可以查看作者申请记录。
- 可以审核作者申请。
- 可以在用户列表中直接将读者提升为作者。
- 可以管理分类和站点设置。
- 不可以发布、上传或修改任何书籍内容。

### 超级管理员

- 拥有审核人员的全部能力。
- 可以创建和管理审核人员账号。
- 不可以发布、上传或修改任何书籍内容。

## MVP 功能

### 认证

- 前台用户通过用户名和密码注册。
- 注册时昵称默认等于用户名。
- 前台用户通过用户名和密码登录。
- 登录用户可以修改昵称和密码。
- 前台用户可以上传头像。
- 后端签发认证会话或 Token。
- 后端能够区分前台用户体系和后台运营体系。
- 新注册用户默认角色为读者。
- 后台运营账号由系统初始化和超级管理员创建，不通过前台注册产生。

### 搜索

- 支持按书名、作者和可选关键词搜索小说。
- 返回基础书籍卡片信息：书名、作者、分类、简介摘要和最新章节信息。
- 首页首屏展示推荐榜单，旁边保留分类入口和新书速递。推荐榜单只按创建时间、章节数或推荐度等确定性字段排序，不做推荐算法。
- 新书速递最多展示 10 本。
- 首页同时承载搜索结果展示，`/search` 仅保留兼容跳转。
- 首页搜索结果支持分页，并允许用户选择每页 `10`、`20`、`50` 或 `1-100` 自定义页数。

### 阅读

- 小说详情页展示元数据和章节列表。
- 章节阅读页展示章节标题和正文。
- 阅读器应提供舒适的排版和页面布局。
- 章节正文要求登录后访问。
- 阅读器支持基础字号、浅色/深色主题和章节目录切换。

### 个人书架

- 用户可以把喜欢的书加入书架。
- 书架支持分组、置顶和批量管理。
- 书架首页直接展示未分组书籍；被收进分组的书会折叠成同级分组入口。
- 分组不是默认容器概念，用户不创建分组时，书籍就直接留在书架首页。
- 分组和普通书籍都可以置顶，书架首页按全局置顶顺序混排，而不是先固定分组区再固定书籍区。
- 我的书架页支持分页查看当前用户加入的书籍。

### 作者申请与审核

- 读者可以提交成为作者的申请。
- 同一读者同一时间最多一条待审核申请。
- 后台审核人员可以批准或拒绝作者申请。
- 后台审核人员可以在用户列表中直接将读者提升为作者。
- 超级管理员可以创建审核人员账号。

### 作者上传与作品管理

- 只有作者可以上传 `.txt` 文件。
- 上传表单至少包含书名、分类和简介。
- 后端校验文件类型和大小。
- 上传文件大小限制为 50MB。
- 后端将上传源文件保存到本地。
- 后端从 `第1章`、`第一章`、`Chapter 1` 等标题格式中解析章节。
- 解析后的章节元数据和正文应可用于阅读。
- 上传成功后展示解析结果摘要，包括章节数和首末章节标题。
- MVP 不做上传前章节预览。
- 作者可以新建空小说。
- 作者可以上传 `.txt` 小说，作者由当前登录账号自动决定。
- 作品作者展示为系统内 `username`，不使用自由输入。
- 小说分类只能选择已有分类，不能在小说表单中输入新分类。
- 作者只能管理自己的小说和章节。
- 只有作者可以发布书籍、上传书籍、修改书籍基础信息和维护章节。

### 后台用户与审核管理

- 后台可以搜索前台用户列表。
- 后台可以查看申请记录、审批状态和审核结果。
- 后台可以直接把读者提升为作者。
- 后台不负责发布、上传或修改书籍内容。

### 分类管理

- 分类列表公开可读，用于搜索和作者表单选择。
- 分类新增、重命名、删除仅后台运营账号可操作。
- 已被书籍使用的分类不允许删除。

### 系统设置

- 站点设置公开读取。
- 站点品牌文案和图标仅后台运营账号可维护。

## MVP 暂不包含

- 付费章节。
- 评论和书评。
- 推荐算法。
- 超出简单列表的排行榜算法。
- 审核发布、签约、收益或草稿箱等扩展作者平台能力。
- 移动端 App。
- 第三方 OAuth。
- 分布式对象存储。
- 旧数据兼容迁移；Phase 10 默认允许清空现有数据并按新模型初始化。

## 验收标准

- 新用户可以注册并登录。
- 新注册用户默认为读者，不能直接发布小说。
- 已登录用户可以搜索并阅读小说。
- 已登录用户可以上传头像、加入书架并管理自己的书架分组和置顶。
- 游客可以搜索和查看详情，但访问章节正文会被要求登录。
- 读者可以提交作者申请，并能看到申请状态。
- 后台审核人员可以审核申请，也可以在用户列表中直接把读者提升为作者。
- 超级管理员可以创建审核人员账号。
- 作者可以上传 `.txt` 文件，并在上传后阅读解析出的章节。
- 作者可以修改自己小说的基础信息和章节内容。
- 非作者不能上传或修改书籍。
- 搜索无结果时必须展示空状态，不出现白屏。
- 后端可以通过 Docker 构建。
- 本地环境可以运行 MySQL 和本地上传文件存储。
- Phase 10 实施时允许清空旧数据并按新账号体系重新初始化。
