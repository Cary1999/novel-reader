# 安全约束

本文件定义 Phase 10 必须遵守的安全边界。

## 认证

- 前台用户通过用户名和密码登录。
- 后台运营账号通过独立后台登录入口登录。
- 密码必须使用安全哈希保存，不能明文存储。
- 登录成功后后端签发 Token。
- 前台和后台不得复用同一登录入口或同一身份语义。

## 角色

角色：

- `guest`：未登录用户。
- `reader`：前台读者。
- `author`：前台作者。
- `reviewer`：后台审核人员。
- `super_admin`：后台超级管理员。

权限：

- 游客可以访问首页、搜索和书籍详情。
- 游客不能访问章节正文。
- 读者可以访问章节正文。
- 读者可以上传头像、加入书架并管理自己的书架分组和置顶。
- 读者不能发布、上传或修改小说。
- 只有作者可以上传小说、创建小说并管理自己的小说和章节。
- 审核人员可以访问后台审核、用户列表、分类管理和系统设置接口。
- 超级管理员可以额外访问审核人员管理接口。
- 后台运营账号不能发布、上传或修改小说。

## 上传安全

- 上传接口必须要求作者登录；作者展示为该用户 `username`。
- 仅允许 `.txt` 文件。
- 必须限制文件大小，MVP 默认限制为 50MB。
- 必须拒绝空文件。
- 必须拒绝无法解析出章节的文件。
- 本地保存路径必须由服务端生成。
- 不得信任原始文件名作为路径。
- API 不得暴露本地绝对路径。
- 头像上传必须要求前台用户登录，并限制图片类型和大小。

## 作品管理安全

- 书籍和章节的新增、修改、删除接口必须要求作者登录。
- 作者只能管理 `owner_user_id` 等于自己的书籍和章节。
- 后台运营账号不能调用书籍和章节内容写接口。
- 游客和读者不能调用任何内容写接口。
- 书架分组、置顶、批量管理和条目变更必须要求前台用户登录，且只能操作自己的书架数据。
- 删除整本小说采用硬删除，删除后公开搜索、详情和阅读接口不可继续访问该书。
- 删除章节后必须在事务内重排同书后续章节序号并刷新书籍统计字段。

## 后台治理安全

- 作者申请审核、用户列表直升作者、分类管理和站点设置写接口仅后台运营账号可操作。
- 审核人员管理接口仅 `super_admin` 可操作。
- 前台用户无法直接登录后台端。

## 分类安全

- 分类新增、重命名、删除仅后台运营账号可操作。
- 小说创建、上传和编辑只能提交已有 `categoryId`。
- 不允许通过小说表单自由输入并自动创建分类。
- 被书籍使用的分类不允许删除。

## 站点设置安全

- 站点设置公开读取接口只返回前台渲染所需字段。
- 站点设置写接口和图标上传接口仅后台运营账号可操作。
- 站点图标路径必须由服务端生成，不信任用户文件名或路径。
- 未上传图标时返回默认图标，不暴露服务端本地绝对路径。

## 输入校验

- 用户名不能为空，并限制长度。
- 昵称不能为空，并限制长度。
- 密码不能为空，并限制最小长度。
- 修改密码必须校验当前密码。
- 书名和分类必填。
- 作者编辑书籍时，作者不可编辑。
- 作者新增或修改章节时，章节标题和正文必填。
- 搜索关键词需要限制长度。
- 分页参数需要限制最大 `pageSize`。
- 自定义 `pageSize` 必须限制在 `1-100`。

## 错误处理

- 登录失败不应泄露用户是否存在的过多细节。
- 文件解析失败应返回可理解但不暴露服务端路径的错误。
- 后端日志可以记录调试信息，但不得记录明文密码或 Token。

## 配置和密钥

- 数据库密码、Token 密钥和后台超级管理员初始密码不得写死在源码中。
- Docker Compose 可以提供本地开发默认值，但生产或共享环境必须改为环境变量注入。
