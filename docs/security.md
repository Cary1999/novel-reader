# 安全约束

本文件定义 MVP 必须遵守的安全边界。

## 认证

- 用户通过用户名和密码登录。
- 密码必须使用安全哈希保存，不能明文存储。
- 登录成功后后端签发 Token。
- 前端通过 `Authorization: Bearer <token>` 调用需要登录的接口。

## 角色

角色：

- `guest`：未登录用户。
- `user`：普通注册用户。
- `admin`：管理员。

权限：

- 游客可以访问首页、搜索和书籍详情。
- 游客不能访问章节正文。
- 普通用户可以访问章节正文。
- 普通用户可以上传小说、创建小说并管理自己的小说和章节。
- 管理员可以访问上传接口、后台上传页面、后台小说管理页面、分类管理页面和后台内容管理接口。
- 管理员可以访问系统设置页面和站点设置写接口。

## 上传安全

- 上传接口必须要求登录；管理员上传展示作者为“系统”，普通用户上传展示作者为该用户 `username`。
- 仅允许 `.txt` 文件。
- 必须限制文件大小，MVP 默认限制为 50MB。
- 必须拒绝空文件。
- 必须拒绝无法解析出章节的文件。
- 本地保存路径必须由服务端生成。
- 不得信任原始文件名作为路径。
- API 不得暴露本地绝对路径。

## 后台管理安全

- 书籍和章节的新增、修改、删除接口必须要求登录。
- 管理员可以管理所有书籍和章节。
- 普通用户只能管理 `owner_user_id` 等于自己的书籍和章节。
- `recommendScore` 仅允许管理员更新；作者编辑自己的书籍时不得修改推荐度。
- 游客不能调用任何内容写接口。
- 删除整本小说采用硬删除，删除后公开搜索、详情和阅读接口不可继续访问该书。
- 删除章节后必须在事务内重排同书后续章节序号并刷新书籍统计字段。
- 上传源文件和 `uploads` 记录默认保留，接口不暴露本地绝对路径。

## 分类安全

- 分类新增、重命名、删除仅管理员可操作。
- 小说创建、上传和编辑只能提交已有 `categoryId`。
- 不允许通过小说表单自由输入并自动创建分类。
- 被书籍使用的分类不允许删除。

## 站点设置安全

- 站点设置公开读取接口只返回前台渲染所需字段。
- 站点设置写接口和图标上传接口仅管理员可操作。
- 站点图标路径必须由服务端生成，不信任用户文件名或路径。
- 未上传图标时返回默认图标，不暴露服务端本地绝对路径。

## 输入校验

- 用户名不能为空，并限制长度。
- 昵称不能为空，并限制长度。
- 密码不能为空，并限制最小长度。
- 修改密码必须校验当前密码。
- 书名和分类必填。
- 后台和用户编辑书籍时，作者不可编辑。
- 后台新增或修改章节时，章节标题和正文必填。
- 搜索关键词需要限制长度。
- 分页参数需要限制最大 `pageSize`。

## 错误处理

- 登录失败不应泄露用户是否存在的过多细节。
- 文件解析失败应返回可理解但不暴露服务端路径的错误。
- 后端日志可以记录调试信息，但不得记录明文密码或 Token。

## 配置和密钥

- 数据库密码、Token 密钥和管理员初始密码不得写死在源码中。
- Docker Compose 可以提供本地开发默认值，但生产或共享环境必须改为环境变量注入。
