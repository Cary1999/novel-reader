# 角色交接模板

角色 Agent 完成任务后，使用本模板向主 Agent 交接。

## 角色

填写角色名称，例如产品 Agent、UI Agent、前端 Agent、后端 Agent、测试 Agent、DevOps Agent 或 Reviewer Agent。

## 任务目标

说明本角色负责解决的问题。

## 输入依据

列出使用的 Harness 文档和关键约束。

示例：

- `docs/product-spec.md`
- `docs/api-contract.md`
- `docs/exec-plans/current.md`

## 改动范围

列出新增、修改或建议修改的文件和模块。

## 关键决策

说明本角色做出的重要取舍，以及原因。

## 验证结果

列出已运行的命令、结果和无法运行的原因。

## 待集成事项

说明主 Agent 集成时需要注意的接口、配置、数据、状态或风险。

## Harness 回填建议

说明是否需要更新产品规格、架构、API 契约、命令、执行计划、决策记录或 skill。
