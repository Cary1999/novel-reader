# UI 规格

本文件记录小说阅读网站的页面结构、交互状态和视觉约束。

## 设计原则

- 参考起点式阅读产品的信息架构和阅读体验，不复制品牌、Logo、视觉资产、精确布局或专有文本。
- 首页和搜索页应服务于发现小说。
- 阅读页应优先保证长文本阅读舒适度。
- 后台页面应偏向工具型界面，强调清晰、可校验和可恢复。

## MVP 页面

- 首页/发现页
- 登录页
- 注册页
- 搜索结果页
- 小说详情页
- 章节阅读页
- 管理员上传页
- 管理员小说管理页
- 我的作品页
- 账号设置页
- 管理员分类管理页

## 页面要求

### 首页/发现页

- 展示搜索入口。
- 展示分类导航。
- 展示新书列表。
- 展示简单榜单，排序规则使用确定性字段。
- 书籍卡片展示书名、作者、分类、简介摘要和最新章节。

### 登录页

- 用户名和密码登录。
- 展示后端返回的错误提示。
- 登录成功后回到来源页或首页。

### 注册页

- 用户名和密码注册。
- 展示基础校验错误和后端错误。
- 注册成功后可以引导登录或直接进入登录态。

### 搜索结果页

- 支持关键词输入。
- 支持分类筛选。
- 展示分页结果。
- 空结果时展示空状态。
- 无匹配结果时必须稳定渲染空状态，不允许页面白屏。

### 小说详情页

- 展示书名、作者、分类、简介、章节数和最新章节。
- 展示章节列表。
- 游客点击章节时引导登录。
- 已登录用户点击章节进入阅读页。

### 章节阅读页

- 展示章节标题和正文。
- 支持基础字号调整。
- 支持浅色/深色主题。
- 支持打开章节目录并切换章节。
- 未登录访问时展示登录引导。

### 管理员上传页

- 只允许管理员访问。
- 表单包含书名、分类、简介和 `.txt` 文件。
- 作者由当前账号自动确定，表单不提供作者输入。
- 分类使用下拉选择已有分类，不使用自由输入。
- 展示文件类型和大小校验错误，最大文件大小为 50MB。
- 上传成功后展示章节数、首章标题和末章标题。
- MVP 不做上传前解析预览。

### 管理员小说管理页

- 只允许管理员访问。
- 展示后台书籍搜索、列表和分页。
- 选择书籍后展示基础信息编辑表单。
- 支持新建空小说。
- 作者字段只展示，不可编辑。
- 分类使用下拉选择已有分类。
- 展示章节列表，并支持选择章节进行编辑。
- 支持新增章节，新增章节默认追加到末尾。
- 支持删除章节和删除整本小说，删除前必须二次确认。
- 保存、新增和删除成功后展示明确成功状态。
- 接口失败、无权限、书籍不存在和章节不存在时展示错误状态。

### 我的作品页

- 登录用户可访问。
- 普通用户只看到自己的小说。
- 支持新建小说、上传小说、编辑小说、删除小说、章节新增/编辑/删除。
- 复用后台小说管理的工具型布局，但文案面向作者本人。

### 账号设置页

- 登录用户可访问。
- 展示用户名、昵称和角色。
- 用户名不可编辑。
- 支持修改昵称。
- 支持输入当前密码和新密码来修改密码。

### 管理员分类管理页

- 只允许管理员访问。
- 展示分类列表。
- 支持新增、重命名和删除分类。
- 分类被书籍使用时展示删除失败提示。

## 必备状态

每个涉及数据请求的页面都应考虑：

- 加载状态
- 空状态
- 错误状态
- 未登录状态
- 无权限状态

## 视觉约束

- 不复制起点读书的品牌、Logo、视觉资产、精确布局或专有文本。
- 阅读页正文区域应优先保证行宽、行高和段落间距舒适。
- 后台页面应使用工具型布局，避免营销式大图和装饰性卡片。
- 页面必须覆盖移动端和桌面端，不允许文字和控件重叠。
