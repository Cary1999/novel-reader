# UI 规格

本文件记录 Phase 10 的页面结构、交互状态和视觉约束。

## 设计原则

- 参考起点式阅读产品的信息架构和阅读体验，不复制品牌、Logo、视觉资产、精确布局或专有文本。
- 读者端服务于发现与阅读。
- 作者端服务于创作与维护自有作品。
- 后台端服务于审核、用户治理和站点治理。
- 三端应共享基础设计语言，但导航语义必须清晰区分。
- 移动端不追求桌面端的多栏复刻，应优先保证触达路径、可读性和控件可点性。

## 页面清单

### 读者端

- 首页/发现页
- 登录页
- 注册页
- 小说详情页
- 章节阅读页
- 账号页
- 我的书架页
- 作者申请状态页或申请区

### 作者端

- 登录页
- 作者工作台 / 我的作品页
- 上传页
- 小说编辑页
- 账号设置页

### 后台端

- 登录页
- 作者申请审核页
- 前台用户列表页
- 分类管理页
- 系统设置页
- 审核人员管理页

## 页面要求

### 读者端首页/发现页

- 展示搜索入口、分类导航、推荐榜单和新书速递。
- 首页同时承载发现内容和搜索结果，`/search` 仅作为兼容跳转。
- 首页首屏默认展示推荐榜单，不再提供“查看全部”按钮。
- 新书速递最多展示 10 本。
- 搜索结果支持分页，并可切换每页 `10`、`20`、`50` 或 `1-100` 自定义页数。
- 书籍卡片展示书名、作者、分类、简介摘要和最新章节。
- 无封面时使用系统占位图，不出现 broken image。

### 读者端登录页 / 注册页

- 用户名和密码登录或注册。
- 展示基础校验错误和后端错误。
- 登录成功后回到来源页或首页。
- 与作者端、后台端登录页在视觉上可关联，但必须清晰提示当前登录的是哪一端。

### 读者端搜索结果页

- 支持关键词输入。
- 支持分类筛选。
- 展示分页结果。
- 空结果时展示稳定空状态，不允许页面白屏。

### 读者端小说详情页

- 展示书名、作者、分类、简介、章节数和最新章节。
- 展示章节列表。
- 游客点击章节时引导登录。
- 已登录读者或作者点击章节进入阅读页。
- 无章节时必须稳定展示空状态。

### 读者端章节阅读页

- 展示章节标题和正文。
- 支持基础字号调整。
- 支持浅色/深色主题。
- 支持章节目录切换。
- 未登录访问时展示登录引导。

### 读者端账号页 / 作者申请区

- 登录读者可访问。
- 展示用户名、昵称和当前前台角色。
- 支持上传头像并即时预览。
- 读者可发起作者申请。
- 已提交申请时展示审核中、已拒绝或已通过状态。
- 申请通过后，应明确提示作者端入口。

### 读者端我的书架页

- 登录前台用户可访问，读者和作者都可以使用。
- 展示当前账号加入书架的小说。
- 支持分组切换、创建、重命名和删除分组。
- 支持单本置顶、取消置顶和批量管理。
- 支持分页浏览和空状态展示。

### 作者端登录页

- 只服务作者登录。
- 未获批读者不应直接进入作者工作台。

### 作者端工作台 / 我的作品页

- 仅作者可访问。
- 展示自己的书籍列表、搜索和分页。
- 支持新建小说、上传小说、编辑小说、删除小说、章节新增/编辑/删除。
- 书籍发布、上传、基础信息修改和章节修改均只允许作者本人操作。
- 不展示推荐度编辑字段。

### 作者端上传页

- 仅作者可访问。
- 表单包含书名、分类、简介和 `.txt` 文件。
- 作者由当前账号自动确定，表单不提供作者输入。
- 分类使用下拉选择已有分类。
- 展示文件类型和大小校验错误，最大文件大小为 50MB。
- 上传成功后展示章节数、首章标题和末章标题。

### 作者端小说编辑页

- 仅作者可访问。
- 支持编辑自己小说的基础信息、封面和章节。
- 支持新增章节，新章节默认追加到末尾。
- 支持删除章节和删除整本小说，删除前必须二次确认。
- 封面支持 JPG/PNG/WebP，最大 10MB。

### 后台登录页

- 只允许后台运营账号登录。
- 不复用前台登录会话。
- 登录成功后进入后台审核/治理页面，而不是读者端或作者端。

### 后台申请审核页

- 只允许后台运营账号访问。
- 展示作者申请列表、状态筛选和审批动作。
- 支持批准和拒绝申请。
- 审核结果要有明确成功/失败反馈。

### 后台前台用户列表页

- 只允许后台运营账号访问。
- 展示前台用户列表及当前前台角色。
- 支持直接将读者提升为作者。
- 不展示书籍编辑入口。

### 后台分类管理页

- 只允许后台运营账号访问。
- 展示分类列表。
- 支持新增、重命名和删除分类。
- 分类被书籍使用时展示删除失败提示。

### 后台系统设置页

- 只允许后台运营账号访问。
- 展示当前站点品牌文案和图标。
- 支持修改品牌主名称、副标题、首页 Hero 文案。
- 支持上传或替换站点图标。
- 图标上传支持 JPG/PNG/WebP/SVG，最大 10MB。

### 后台审核人员管理页

- 只允许超级管理员访问。
- 展示审核人员账号列表。
- 支持创建、启用和禁用审核人员。
- 审核人员页面不暴露内容编辑能力。

## 必备状态

每个涉及数据请求的页面都应考虑：

- 加载状态
- 空状态
- 错误状态
- 未登录状态
- 无权限状态

## 视觉约束

- 不复制第三方阅读站品牌、Logo、视觉资产、精确布局或专有文本。
- 阅读页正文区域应优先保证行宽、行高和段落间距舒适。
- 作者端保持创作工作台语义，后台端保持审核治理语义。
- 后台页面不得出现书籍编辑、章节编辑或上传小说入口。
- 页面必须覆盖移动端和桌面端，不允许文字和控件重叠。
- 封面占位图必须为项目自有资产，不得引用外站图片链接。
